# Sirenproof

> Tie yourself to the mast.

[![CI](https://github.com/sanjubibin/Sirenproof/actions/workflows/ci.yml/badge.svg)](https://github.com/sanjubibin/Sirenproof/actions/workflows/ci.yml)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

Sirenproof is a free, open-source blocker for the websites and apps that pull you off track. You set the
rules while you're calm; it holds you to them when the pull is strongest, and reminds you of your goal
instead of lecturing you. It runs entirely on your device: no account, no cloud, no tracking.
